## v2.0에서 달라진 것

1. **산 이유 / 판 이유를 나눴습니다** — 모달에서 구분(매수/매도/배당)을 고르면 이유 칩도 그에 맞게 바뀝니다.
   - 산 이유 10: 저평가(PER·PBR) · 실적·수주 · 배당 매력 · 업황 바닥 · 고수 의견 참고 · 계획 분할매수 · 물타기 · 차트·수급 · 뉴스·테마 추격 · 불안·조급(FOMO)
   - 판 이유 7: 목표수익 도달 · 실적·배당 훼손 · 더 좋은 종목 교체 · 리밸런싱·현금화 · 원칙 손절 · 하락 공포·불안 · 단기 차익 유혹
   - 배당: 정기 배당 · 특별·분기 배당 · 배당 매력
   - **`+ 직접 입력`** 으로 내 태그를 즉석에서 추가(구분별로 기억, 시트 `설정` 탭 `이유태그` JSON 에도 저장).
   - **옛 태그는 지우지 않습니다.** 예전 기록의 `저평가`·`배당`·`리밸런싱`·`감정·불안` 등은 점선 칩으로 그대로 남고,
     필터·성적표에도 함께 나옵니다(데이터 로드 시 태그를 걸러내지 않음).
2. **"안 팔고 그대로 뒀다면?" 매도 복기** — 매도마다 매도단가 ↔ 현재가를 비교합니다.
   - 내려갔으면 초록 `잘 팔았다! +OO원 손실 방어 (−O.O%)`, 올라갔으면 주황 `안 팔았으면 +OO원 더 (+O.O%)`
   - 매매 기록 맨 위 **「내 매도 복기 요약」** 카드: 잘 판 건수 vs 아쉬운 건수를 막대로 비교하고, 합계(방어 − 기회비용)를 한 줄로.
   - **판 이유별 복기** 카드, **산 이유별 성적표**(수익률·승률 게이지), **분위기별** 게이지.
3. **종목 복기 상세** — 홈 `보유 종목` 또는 `매매 기록`에서 **종목명을 누르면** 한 장으로:
   그 종목에 넣은 돈 → 지금 금액(안 샀으면 현금 그대로), 평가·실현·배당, 판 기록 복기, 매수 이유·분위기·매도조건·메모 타임라인, 관련 고수 카드.
4. **현재가 자동** — 구글 시트가 연결돼 있으면 **앱을 열 때** 백그라운드에서 `action=prices` 를 한 번 불러 현재가를 조용히 갱신합니다.
   `Code.gs v1.2.0` 부터는 **네이버 금융**에서 종목코드(검색)와 현재가를 자동으로 채웁니다(실패 시 기존 숫자 유지, GOOGLEFINANCE 수식은 보존).

## 앱으로 설치 (v1.1)

주소창 없는 앱처럼 쓰려면 한 번만 설치하면 됩니다. 같은 주소·같은 기록을 그대로 씁니다.

- **안드로이드 크롬 / 웨일 / 삼성인터넷**: 페이지를 연 뒤 오른쪽 위 **메뉴(점 3개)** → **앱 설치**(또는 **홈 화면에 추가**).
  앱이 설치 가능해지면 상단 오른쪽에 **⬇ 설치 버튼**이 나타나고, ⚙ 설정 → **앱으로 설치**에서도 한 번에 됩니다.
- **아이폰·아이패드(사파리)**: **공유** → **홈 화면에 추가** → **추가**.
- 설치 후에는 주소창·브라우저 탭 없이 열리고, 앱 전환기에서도 독립 앱으로 뜹니다.
- 이미 열어 둔 탭이 있다면 **탭을 닫고 새로 연 뒤** 설치하세요(예전 화면에는 새 매니페스트가 없습니다).

`sw.js` 는 앱 껍데기(화면·매니페스트·아이콘)만 캐시합니다. 화면 문서는 항상 네트워크 최신을 먼저 받고,
구글 시트(`script.google.com`)·`#s=` 해시·POST 저장 요청은 건드리지 않습니다. 새 버전은 `CACHE` 이름을 올리면 바로 반영됩니다.

## 4개 탭

1. **홈** — 진짜 수익(순수 원금 대비), 총 자산·누적 실현수익+배당, 위기 신호등 3개
   (담보비율 버퍼 / 고점 대비 낙폭 / 상위 종목 집중도), 자산 추이 차트(호버·탭 툴팁), 보유 종목·현재가 수정
   - **`+ 기존 보유 추가`** (보유 종목 카드 헤더) — 예전부터 들고 있던 종목을 종목명·수량·평단만으로 등록
     (현재가·섹터는 선택, `저장하고 하나 더`로 여러 종목 연속 입력, 같은 종목은 수량·평단 자동 합산)
2. **매매 기록** — `+ 매매 기록하기` 바텀시트(10초 입력), **내 매도 복기 요약**, 산 이유별 성적표, 판 이유 복기,
   시장 분위기별 매수, 전체/매수/매도/배당/기존 보유 + 태그 필터 타임라인(카드 탭 = 수정·삭제, 종목명 탭 = 종목 복기)
   - 입력 항목: 날짜 · 종목명 · 구분(매수/매도/배당) · 수량 · 단가 · 재원(현금/담보대출) ·
     이유(구분에 따라 산 이유 10 / 판 이유 7 / 배당 3, 다중 선택, `+ 직접 입력`) · 당시 분위기(공포/보통/과열) · 목표 기간(단기/중기/장기) · 매도 조건 · 메모
3. **배당** — 올해 예상 배당금·월 평균·배당수익률, 12개월 막대(클릭/호버로 종목 확인),
   공시 변경 알림(예상→확정 금액, 배당기준일 변경), 종목별 연간 배당
4. **고수 매칭** — 오늘의 매칭 기준 3개(지표 이벤트 · 보유 섹터 · 아카이브 개념)를
   지금 데이터에서 계산해 상위 카드 3개를 고르고, 왜 매칭됐는지 한 줄로 보여 줌 + 원문 모달

## 계산 규칙 (중요)

- **순수 원금** = 내 돈으로 새로 넣은 돈. 배당·매도대금 **재투입은 원금이 아님** → 재투입 착시 제거
- **총 자산(순자산)** = 보유 평가액 + 예수금 − 담보대출 잔액
- **진짜 수익** = 총 자산 − 순수 원금
- **누적 실현수익 + 배당** = 매도 실현손익(FIFO) + 배당 입금
- **담보비율** = 보유 평가액 ÷ 담보대출 잔액 (기준 140% 아래로 내려가면 마진콜, 남은 하락 여유 % 표시)
- **집중도** = 가장 큰 한 종목 ÷ 보유 평가액 (기본 주의 30% / 위험 45%)
- **고점 대비 낙폭** = 기록된 최고 총자산 대비 현재 (5% / 12% 기준)
- 이유 태그 성과는 **매도로 이어진 매수 lot만** FIFO로 계산(아직 안 판 태그는 “아직 매도 없음”)
- 매수는 순자산을 바꾸지 않습니다(예수금 → 주식). 평가액은 현재가를 바꿔야 움직입니다.

### 기존 보유(초기보유) 규칙 — v1.2

- 홈 `+ 기존 보유 추가`로 넣은 종목은 「매매기록」에 **`구분: 초기보유`** 로 저장됩니다(앱 안에서는 `side: 'init'`).
- 보유 수량·평단·평가액·집중도·담보비율·배당수익률 분모**에는 정상 합산**됩니다. 같은 종목을 여러 번 넣어도 수량·평단이 합산됩니다.
- **예수금은 차감하지 않습니다**(이미 들고 있던 주식이므로).
- **이유 태그별 성과·시장 분위기별 통계에는 섞이지 않습니다.** 매도는 FIFO로 기록된 매수 lot을 먼저 소진하고,
  기존 보유 lot은 그다음에 씁니다 — 그래서 이미 쌓인 태그·분위기 성과가 소급해서 바뀌지 않습니다.
  (기록된 매수보다 많이 팔면 그 초과분은 기존 보유 lot에서 나가고, 실현손익에는 평단 기준으로 잡힙니다.)
- **`매수 총액을 순수 원금에도 함께 더하기`** (기본 켜짐) — 켜면 그 매수금액이 순수 원금에 더해져 진짜 수익이 왜곡되지 않습니다.
  이미 순수 원금에 포함해 둔 사람은 꺼 두면 됩니다. (원금에 더한 금액은 `설정 → 순수 원금`이 아니라 기존 보유 기록에 붙어 있어,
  기록을 지우면 원금에서도 같이 빠집니다.)
- 현재가를 비워 두면 평단과 같게 시작합니다(수익 0). 나중에 보유 종목의 현재가 배지로 바꾸면 됩니다.
- 섹터를 직접 고르면 종목별 섹터로 저장되어 집중도·고수 매칭에 쓰입니다(`data.sectors`).

## 구글 시트 연결

`apps-script/Code.gs` 맨 위 주석의 5단계를 따라 배포한 뒤,
앱 ⚙ 설정 → 구글 시트 연결에 `.../exec` 주소를 넣습니다.
연결되면 주소창이 `#s=<base64>` 로 바뀌고, 그 주소를 즐겨찾기하면 다음부터 자동 연결됩니다
(`my-portal`, `wealth-plan` 과 같은 방식).

시트 탭: `매매기록` · `배당공시` · `고수매칭` · `자산추이` · `설정` · `시세`

- **v1.2부터 Code.gs도 v1.2.0으로 다시 배포해야 기존 보유와 현재가 자동이 온전히 동작합니다.**
  (`구분: 초기보유` ↔ 앱 `init`, `설정` 탭의 `종목섹터`·`이유태그` JSON, 기존 보유의 **ID 접두어 `i1-`/`i0-`** = 원금 포함/미포함 표식)
  예전 스크립트를 그대로 두면 앱이 저장할 때는 문제없지만, 다시 불러올 때 `초기보유` 행이 `매수`로 보입니다.
  앱은 ID 접두어로 이를 되살리지만, 새로 배포하는 편이 확실합니다.

### 현재가 자동 (Code.gs v1.2.0)

- `save`·`prices` 요청마다: 매매기록에 있는데 `시세` 탭에 없는 종목 줄 추가 → 종목코드가 비면 네이버 금융 검색
  (`ac.stock.naver.com`)으로 6자리 코드 조회 → 코드가 있으면 현재가(`m.stock.naver.com/api/stock/{code}/basic`)로 C열 갱신
- 60초 캐시로 네이버 호출을 줄이고, 응답 실패 시에는 시세 탭에 있던 숫자를 그대로 돌려줍니다.
- C열에 `GOOGLEFINANCE` 수식이 있는 칸은 **수식을 지우지 않습니다.** 코드를 직접 적어 둔 종목은 검색을 건너뜁니다.
- 앱은 열 때마다 한 번 `prices` 를 불러 조용히 반영하고(⚙ 설정의 `불러오기` 도 그대로), 실패해도 기존 숫자를 유지합니다.

예전 방식(`시세` 탭 C열 `=IF(B2="","",GOOGLEFINANCE("KRX:" & B2))`)도 그대로 쓸 수 있습니다(지연 시세·참고값).
