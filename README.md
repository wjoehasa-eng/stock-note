# 주식노트 (stock-note) v1.1

토스 스타일로 만든 **매매 복기 · 배당 · 위기 신호 · 고수 매칭** 웹앱. 1차 설계·시제품입니다.

**바로 열기: https://wjoehasa-eng.github.io/stock-note/** (예시 화면만 보기: `?demo=1`)

- 파일: `index.html` (단일 파일, 로컬 파일로 그대로 열어도 동작)
- 설치형 앱(PWA): `manifest.webmanifest` · `sw.js` · `icon-192.png` · `icon-512.png` · `icon-192-maskable.png` · `icon-512-maskable.png` · `apple-touch-icon.png` (아이콘은 `test/gen_icons.py` 로 재생성)
- 백엔드(선택): `apps-script/Code.gs` — 본인 구글 시트에 붙여 배포
- 저장: ① 이 브라우저(localStorage) ② (연결 시) 본인 구글 시트
- 검증 스크립트: `test/screenshots.py`(화면), `test/pwa_check.py`(매니페스트·아이콘·서비스 워커·설치 UI)
- 개인정보: 이 폴더의 코드·예시 데이터에는 실제 보유 종목·수량·금액이 **하나도** 없습니다.
  기본 화면은 삼성전자·SK텔레콤·맥쿼리인프라·KB금융으로 만든 **가상 예시**입니다.

## 앱으로 설치 (v1.1)

주소창 없는 앱처럼 쓰려면 한 번만 설치하면 됩니다. 같은 주소·같은 기록을 그대로 씁니다.

- **안드로이드 크롬 / 웨일 / 삼성인터넷**: 페이지를 연 뒤 오른쪽 위 **메뉴(점 3개)** → **앱 설치**(또는 **홈 화면에 추가**).
  앱이 설치 가능해지면 상단 오른쪽에 **⬇ 설치 버튼**이 나타나고, ⚙ 설정 → **앱으로 설치**에서도 한 번에 됩니다.
- **아이폰·아이패드(사파리)**: **공유** → **홈 화면에 추가** → **추가**.
- 설치 후에는 주소창·브라우저 탭 없이 열리고, 앱 전환기에서도 독립 앱으로 뜹니다.
- 이미 열어 둔 탭이 있다면 **탭을 닫고 새로 연 뒤** 설치하세요(예전 화면에는 새 매니페스트가 없습니다).

`sw.js` 는 앱 껍데기(화면·매니페스트·아이콘)만 캐시합니다. 화면 문서는 항상 네트워크 최신을 먼저 받고,
구글 시트(`script.google.com`)·`#s=` 해시·POST 저장 요청은 건드리지 않습니다. 새 버전은 `CACHE` 이름을 올리면 바로 반영됩니다.

## 여는 법

`index.html` 을 그냥 열어도 되고, 로컬 서버로 열면 더 확실합니다.

```bash
cd work/stock-note
python3 -m http.server 8791
# 브라우저에서 http://127.0.0.1:8791/index.html
```

- `?demo=1` — 언제나 예시 데이터로 시작
- 저장된 기록이 없으면 자동으로 예시 데이터 + 상단 안내 배너
- 상단 배너의 **내 기록으로 시작** → 빈 기록에서 시작(입력하면 그때부터 저장)
- 빈 기록에서는 홈에 **“순수 원금을 먼저 넣으면 진짜 수익이 계산됩니다”** 안내 카드가 뜹니다

## 4개 탭

1. **홈** — 진짜 수익(순수 원금 대비), 총 자산·누적 실현수익+배당, 위기 신호등 3개
   (담보비율 버퍼 / 고점 대비 낙폭 / 상위 종목 집중도), 자산 추이 차트(호버·탭 툴팁), 보유 종목·현재가 수정
2. **매매 기록** — `+ 매매 기록하기` 바텀시트(10초 입력), 이유 태그별 매수/매도 건수·승률·평균 수익률,
   시장 분위기별 매수 횟수, 전체/매수/매도/배당 + 태그 필터 타임라인(카드 탭 = 수정·삭제)
   - 입력 항목: 날짜 · 종목명 · 구분(매수/매도/배당) · 수량 · 단가 · 재원(현금/담보대출) ·
     산 이유(7개 다중 선택) · 당시 분위기(공포/보통/과열) · 목표 기간(단기/중기/장기) · 매도 조건 · 메모
3. **배당** — 올해 예상 배당금·월 평균·배당수익률, 12개월 막대(클릭/호버로 종목 확인),
   공시 변경 알림(예상→확정 금액, 배당기준일 변경), 종목별 연간 배당
4. **고수 매칭** — 오늘의 매칭 기준 3개(지표 이벤트 · 보유 섹터 · 아카이브 개념)를
   지금 데이터에서 계산해 상위 카드 3개를 고르고, 왜 매칭됐는지 한 줄로 보여 줌 + 원문 모달

## 계산 규칙 (중요)

- **순수 원금** = 내 돈으로 새로 넣은 돈. 배당·매도대금 **재투입은 원금이 아님** → 재투입 착시 제거
- **총 자산(순자산)** = 보유 평가액 + 예수금 − 담보대출 잔액
- **진짜 수익** = 총 자산 − 순수 원금
- **누적 실현수익 + 배당** = 매도 실현손익(FIFO) + 배당 입금
- **담보비율** = 보유 평가액 ÷ 담보대출 잔액 (기준 140% 아래로 내려가면 마진콜, 남은 하락 여유 % 표시)
- **집중도** = 가장 큰 한 종목 ÷ 보유 평가액 (기본 주의 30% / 위험 45%)
- **고점 대비 낙폭** = 기록된 최고 총자산 대비 현재 (5% / 12% 기준)
- 이유 태그 성과는 **매도로 이어진 매수 lot만** FIFO로 계산(아직 안 판 태그는 “아직 매도 없음”)
- 매수는 순자산을 바꾸지 않습니다(예수금 → 주식). 평가액은 현재가를 바꿔야 움직입니다.

## 구글 시트 연결

`apps-script/Code.gs` 맨 위 주석의 5단계를 따라 배포한 뒤,
앱 ⚙ 설정 → 구글 시트 연결에 `.../exec` 주소를 넣습니다.
연결되면 주소창이 `#s=<base64>` 로 바뀌고, 그 주소를 즐겨찾기하면 다음부터 자동 연결됩니다
(`my-portal`, `wealth-plan` 과 같은 방식).

시트 탭: `매매기록` · `배당공시` · `고수매칭` · `자산추이` · `설정` · `시세`

`시세` 탭 C열에 `=IF(B2="","",GOOGLEFINANCE("KRX:" & B2))` 를 넣고 종목코드를 채우면
⚙ 설정 → **현재가 자동 불러오기** 로 평가액을 갱신할 수 있습니다(지연 시세·참고값).

## 검증 (2026-11-24)

Playwright/Chromium 로컬 서버(8791·8792)와 `file://` 로 확인:

- 라이트/다크, 데스크톱 1280px·1024px·모바일 390px 렌더 확인, 콘솔 오류 0건

  타임라인 15→16건, 보유 종목에 현대차 추가, 태그 카드 `저평가 매수 4`·`실적·수주 매수 2`,
  분위기 타일 `공포 4→5회` 즉시 갱신
- 수정(수량 변경) → 저장, 삭제(두 번 눌러 확인) → 15→14건
- 필터(매도 3건 / 매도+배당 1건), 현재가 수정 → 총 자산 변동, 배당 6월·7월 막대 상세
- 테마 자동→라이트→다크 순환, `#s=<base64>` 해시 파싱(잘못된 주소는 빨간 점)
